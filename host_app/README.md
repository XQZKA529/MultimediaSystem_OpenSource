# 影序 · FPGA 素材管理上位机

本程序用于为当前项目的**双板系统**准备 SD 卡素材。它可以转换图片和音频、安排图片播放顺序、配置字幕和台标，并在写卡后核验实际目录顺序。

## 源码构建（绿色版）

本目录即绿色版源码。安装 Python 3.12 后，在仓库根目录执行：

```powershell
pip install -r host_app/requirements.txt
powershell -File host_app/build_standalone.ps1
```

产物为 `host_app/dist/FPGA-Media-Manager-Standalone.exe`；仓库根目录也提供预编译的单文件 EXE，可直接使用。

## 启动程序

使用 Windows 10/11 64 位系统，双击：

```text
host_app/dist/FPGA-Media-Manager-Standalone.exe
```

这是单文件版本，复制该 EXE 即可使用，不需要安装 Python、Pillow 或其他音频工具。启动时会将运行组件解压到临时目录，首次启动可能需要等待。

界面会按 Windows 系统显示缩放调整。修改系统缩放后请重新启动程序；多显示器之间缩放比例不同时，Windows 会对窗口进行缩放。

如果写 SD 卡时提示无法读取磁盘目录项，请关闭程序，右键 EXE，选择“以管理员身份运行”。

## 使用步骤

1. 打开“素材与播放顺序”，点击“添加图片”，选择 JPG、PNG 或 BMP。
2. 在列表中拖动图片卡片排序；也可以使用“上移”和“下移”按钮。拖动时的绿色横线表示插入位置，按 Esc 可取消拖动。
3. 选中图片，在右侧选择转换方式，并按需填写字幕、选择这张图片的配音。
4. 如需单独播放音乐，在“音频管理”中添加 MP3 或 WAV；如需台标，在“台标设置”中选择图片。
5. 可使用“保存项目”记录素材和设置，下次用“打开项目”继续编辑。项目保存的是原素材路径，移动或删除原文件后需要重新选择素材。
6. 打开“写入 SD 卡”，选择目标磁盘，确认盘符、卷标和容量后点击“转换并写入 SD 卡”。
7. 等待程序报告写入和核验成功，安全移除 SD 卡，将其插入 media 板并复位设备。

### 图片转换

| 方式 | 输出 | 显示效果 |
| --- | --- | --- |
| 等比黑边 · 720p | 1280×720 BMP | 保持原图比例，空白区域补黑 |
| 拉伸 · 720p | 1280×720 BMP | 铺满画面，可能改变原图比例 |
| 保持原尺寸 | 原尺寸 BMP | 宽、高均须在 1–4096 像素内；FPGA 显示时仍会等比缩放并补黑边 |

输出为 FPGA 可读取的 24 位、无压缩、正高度 BMP。普通图片最多 256 张。

### 独立音频与图片配音

“音频管理”中的音频和图片设置中的“图片配音”是独立的：

- **独立音频**：写入 SD 卡后，可通过 FPGA 文件浏览器选择播放，也可作为背景音乐。
- **图片配音**：上位机将其转换为与图片同名的 WAV；FPGA 显示图片后自动查找并播放。开启自动轮播时，有配音的图片会等待配音播放完成后再切换。

音频转换结果为 48 kHz、16 位 PCM WAV，支持单声道和立体声。普通 WAV 总数最多 64 首，包括独立音频和图片配音。

### 字幕与台标

- 字幕按图片分别设置，上位机会生成与图片同名的 TXT。当前 FPGA 只支持单行、最多 256 个可打印 ASCII 字符，**不支持中文**；长字幕会滚动。
- 使用自动字幕时，需要在 FPGA 的 **SD SUBTITLE** 设置中开启 **AUTO**。自动轮播也需要在 FPGA 菜单中开启。
- 台标转换为固定的 `OVERLAY.BMP`，尺寸为 64×64，显示在画面右上角。当前台标不支持透明显示。

## SD 卡要求与播放顺序

- 使用 FAT32 格式、512 字节逻辑扇区的可移动 SD 卡，素材放在根目录。
- 写入前必须自行备份并清空根目录；程序不会自动删除文件或格式化 SD 卡。
- 程序先在电脑上转换素材，再按照列表顺序创建图片文件，并在写完后核验文件内容及 FAT32 根目录的实际图片枚举顺序。
- 如果提示顺序核验失败，可能是目录中残留的已删除目录项影响了顺序；请自行备份、重新准备空的 FAT32 卡后重试。写入失败或中途拔卡可能留下部分文件，请检查目标卡。
- “导出转换素材”只生成文件供检查或手动使用；之后用其他软件复制文件，**不能保证 FPGA 播放顺序**。如需验证顺序，请使用程序的“写入 SD 卡”。

## 从源码运行与重新打包

以下命令在项目根目录执行。源码运行需要 Python 3.10 或更高版本：

```powershell
python -m pip install -r host_app/requirements.txt
python host_app/app.py
```

重新构建单文件程序时，先安装项目依赖，再安装 PyInstaller：

```powershell
python -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File host_app/build_standalone.ps1
```

生成的 EXE 位于 `host_app/dist/`。

单文件版本使用 miniaudio 解码 MP3 和 WAV，其 MIT 许可证可在程序的“关于 / 许可证”页面查看。
