# 资源优化位宽与生命周期审查

当前保留组合：media 8968、render 8811 Slice。表中“保留”描述该组合；试验字段不等于已经写回。范围依据 RTL 的实际赋值、比较及消费阶段，不只依据正常业务的典型值。最终面积仍以 post-hold 报告为准。

| 对象 | 保留位宽 | 范围及必须保留的语义 |
|---|---:|---|
| BMP `lane` | 6 | 从 0 到 54，54 为停止消费头字节的终态；需要容纳终值，不能只按 54 个地址计算。 |
| BMP 原始 `w/h` | 32 | 保留完整输入以拒绝非法高位；输出尺寸为 13 位。固定参数下的高位非法标志候选没有因 FF 减少而直接保留。 |
| BMP `row_stride` | 32 | 外部结果保持完整宽度；乘法仅使用低 15 位，因 13 位宽度产生的对齐步长最大为 24576。 |
| BMP `span` | 28 | 低 15 位步长乘 13 位高度；28 位保留完整乘积。 |
| BMP `end_wide` | 33 | 32 位文件偏移加上述跨度，额外一位保留越界进位；文件大小、偏移、payload_end 不缩小。 |
| 几何两次交叉乘积 | 29 | 13 位源尺寸乘 16 位目标尺寸，最大值小于 2^29；保留所有无效输入的算术结果。 |
| 几何 `remainder/divisor` | 14 / 13 | 含恢复除法的移位比较位；round-to-even 需要完整余数及商最低位。不能只因结果尺寸为 16 位而缩小乘积。 |
| 几何 `bit_index` | 5 | 29 次除法步进及终止值；尝试复用被除数/商/乘积存储的候选未通过面积筛选，主线保持原数据寄存器。 |
| RGB888 `carry` | 24 | phase0 完整捕获；phase1 只需低 16 位；phase2 只需低 8 位。合并互斥生命周期，不减少任何颜色位。 |
| RGB `pixel_count` | 20 | 默认完整帧 921600 像素及终值。保留原 20 位参数边界/回绕行为，覆盖 FRAME_PIXELS=0、负值、2^20。 |
| LBA `burst_nsec` | 参数化，默认 7 | 必须表示 MAX_BURST=64 本身；按参数低 16 位及原零值语义计算。外部 blk_count 仍为 16 位。 |
| LBA `cur_nsec/sec_need_r` | 24 | 32 位文件大小向上取整到扇区数最大为 2^23，需要包含这个端点，不能裁成 23 位。 |
| FAT `walk_cluster` | 32 | 外部簇号仍完整进入非法输入检查。不能利用 FAT 合法簇只占 28 位而提前丢弃输入高位。 |
| FAT FILE/MAP 跳数 | 24 / 20 | 分别保留原循环检测及上限语义；DIR 跳数仍为 32 位。互斥计数器复用试验未保留。 |
| FAT `map_use_bytes` | 32 | 合法挂载后至多一个簇、最大 65536，17 位足够表示端点；裁剪候选已验证但最终 Slice 更高，因此未写回。 |
| FAT LFN 字符值 | 16 | 必须区分零、0xffff 终止/填充值和 Unicode；只保留低八位会破坏替换字符及结束判定。 |
| FAT LFN ordinal/base/length | 原 8 位 | 保留原低五位 ordinal 选择、base 默认 247、length 特例 255 和八位乘积截断。新共享 RAM 试验须覆盖全部 32 项。 |
| FAT 控制状态 | 7 | 72 个合法诊断状态及 56 个非法控制码的一拍默认恢复；编码变化不能改变对外诊断值。 |
| FIFO AW=10 指针 | 11 | 地址低十位加回绕位，容量仍为 1024；高位用于占用量/满空判定，不能裁掉。异步 FIFO Gray 同步链不改。 |
| DDC `tick` | 默认 10 | HALF=750，计数至 HALF−1；参数化位宽为 ceil(log2(HALF))。 |
| DDC `age` | 默认 21 | TIMEOUT=1500000，超时当拍还会递增，须表示 TIMEOUT+1；特殊参数保留 32 位回退。SCL/SDA 两级同步寄存器不改。 |
| Goertzel `s1/s2` | 默认有符号 25 | 完整状态精度、符号及逐频带访问顺序不改；STW=26 等参数使用原通用回退。 |
| 协议序号、对象字段、文件大小、LBA | 原接口宽度 | 本轮不以减小这些字段精度节约资源；本地控制索引与外部字段分别审查。 |

同步存储的准备及消费约束：

- 菜单、字形、坐标及覆盖率 ROM 吸收原有流水线，原坐标越界截断、默认值与像素吞吐保持不变。
- FAT 目录元数据沿地址、等待、消费阶段读取；名称、扇区和缓存未初始化的数据只能在原有效条件成立后消费。
- storage_service 的 BMP、TXT、MAP 参数即使并发到达也各有独立存储，不能把 pending 与活动请求混为一个生命周期。BRAM 试验逐拍检查公共输出，另检查每个参数从其捕获到消费的完整宽度；复位后的未捕获私有数据不得触发启动。
- BRAM9K 原生九位模式的地址低三位承担写使能作用。只读 ROM 的低位为零并不能作为写 RAM 的接线模板。2026-10-16 已按 TD 导出映射修正独立试验，并通过完整 32 位原生写穿透/保持探测；旧零掩码失败日志保留。
